Jom Al-Quran: 56 tables, back from Oracle

7 November 2026 · 4 min read

The other database from my UTP days models Jom Al-Quran, a business running Quran and Arabic classes: students and their guardians, teachers and their schedules, courses, invoices, payments, and the websites and social media behind it all. It was a group assignment, built in Oracle like the company one.

  • 56 tables
  • 1,459 rows
  • 80 foreign keys
  • 0 broken links

Bringing it back

The original lived in a Word report: Oracle SQL and screenshots, runnable only on a lab machine. I had an AI coding agent port it to SQLite, repair the three typos that stopped it loading (two split inserts, 120 missing semicolons and two malformed foreign keys), check every relationship, and wrap it in tests. Every table, column and row is otherwise exactly as we submitted it.

For this page, the names, IC numbers, emails and phone numbers are all replaced with obviously fake ones. Each original maps to the same fake value everywhere, so every join still lines up.

What I'd design differently now

Running it properly also meant reading it critically. It loads cleanly and every query works, but with a few years of hindsight:

  • Too many link tables. 36 of the 56 tables are link tables, and in the data most of them are really one-to-many. A single foreign key would do, and query four wouldn't need thirteen tables.
  • One person, three names. A guardian, a client and a student can all be the same human, with nothing tying them together. Today I'd have one Person table and roles on top.
  • The same fact stored twice. Schedules record their student and teacher directly and in two link tables. They agree now, which is exactly when duplicates look harmless.
  • The documentation drifted. The report's schema list and its CREATE TABLEs disagree on a few tables. A test that checks one against the other would have caught it.

None of that is a reason to be embarrassed by it. It's the same lesson every project since has taught me: write the model down, then check the real thing against it.
